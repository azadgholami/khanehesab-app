# خانه‌حساب – بسته آماده‌سازی انتشار

## محتویات
- `index.html`: نسخه اصلی برنامه با دکمه راهنمای نصب PWA
- `manifest.webmanifest`: مشخصات نصب و نمایش برنامه
- `service-worker.js`: پوسته آفلاین و به‌روزرسانی cache
- `icons/`: آیکون‌های 192 و 512 پیکسل
- `capacitor.config.json` و `package.json`: نقطه شروع بسته‌بندی Android/iOS با Capacitor

## انتشار وب / PWA
تمام فایل‌ها و پوشه‌ها را در ریشه مخزن GitHub Pages قرار دهید؛ به‌طوری‌که `index.html`، `manifest.webmanifest`، `service-worker.js` و پوشه `icons` هم‌سطح باشند. آدرس فعلی پروژه باید HTTPS باشد. پس از Commit و پایان GitHub Pages deployment، در Chrome گزینه Install app یا در Safari آیفون گزینه Share → Add to Home Screen را انتخاب کنید.

## وضعیت درآمدزایی
این بسته هنوز تبلیغ زنده یا پرداخت واقعی فعال نمی‌کند. برای تبلیغ در نسخه وب باید حساب ناشر و تأیید شبکه تبلیغاتی و کد تبلیغاتی واقعی تهیه شود. برای AdMob در نسخه native باید پروژه Android/iOS و شناسه‌های اپ و واحدهای تبلیغاتی ثبت‌شده اضافه شوند. اشتراک حرفه‌ای نیز به درگاه پرداخت/فروشگاه و اعتبارسنجی سمت سرور نیاز دارد؛ فعال‌سازی پرداخت بدون کلیدهای رسمی پذیرنده و بک‌اند امن، دریافت پول واقعی را ممکن نمی‌کند.

## موارد لازم برای راه‌اندازی درآمد واقعی
1. انتخاب درگاه ایرانی و ارائه اطلاعات پذیرندگی/کلیدهای رسمی آن.
2. تعیین امکانات دقیق نسخه حرفه‌ای و قیمت/دوره اشتراک.
3. ثبت حساب توسعه‌دهنده Google Play و Apple Developer و آماده‌سازی اطلاعات حقوقی/مالی و سیاست حریم خصوصی.
4. ایجاد نسخه native با Capacitor و افزودن SDK تبلیغات/پرداخت سازگار با فروشگاه مقصد.
5. آزمون پرداخت، تمدید/لغو اشتراک، بازیابی خرید و حذف تبلیغات.

## نکته مهم داده‌ها
پیش از جایگزینی فایل‌ها، از داده‌های داخل برنامه یک پشتیبان رمزگذاری‌شده بگیرید. این بسته، ساختار فعلی برنامه و تنظیمات Supabase موجود در فایل را حفظ می‌کند. کلید publishable موجود در کلاینت، کلید عمومی است؛ دسترسی واقعی باید با RLS و سیاست‌های صحیح جدول Supabase محدود شده باشد.
